# P0 Read API Implementation Plan

> **For agentic workers:** REQUIRED SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add immutable P0 snapshots for inventory, equipment, bank, skills, and location while preserving each domain's availability semantics.

**Architecture:** Follow the existing static `getState(Client)` pattern. Share only an immutable `ItemSlot` value used by the three item-container domains; keep each domain's lifecycle and derived queries in its own utility class. Read native RuneLite state once per capture and never retain mutable client objects.

**Tech Stack:** Java 11, RuneLite API 1.12.36, Lombok getters, Gradle assertion-based self-tests.
